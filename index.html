Leitor

Aplicativo pessoal de leitura de livros em PDF, de uso exclusivo de Kaique Oliveira.

O Leitor permite abrir livros guardados no Google Drive do próprio dono, marcar trechos e organizar anotações. Não é um serviço público e não aceita cadastro de outras pessoas.

Política de privacidade

Quais dados o app acessa. Com autorização do dono da conta, o Leitor lê (somente leitura) os arquivos de uma pasta específica do Google Drive dessa mesma conta, para exibir os livros.

Como os dados são usados. Os arquivos são usados apenas para exibição ao próprio dono. Nada é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos de IA.

Armazenamento. O app não guarda cópias dos livros. As credenciais de acesso ficam apenas no servidor privado do dono.

Revogação. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Uso de dados do Google. O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
